## Selected Work

### Burgh Threads Manufacturing Simulation
**Simio · Experiment Design · Operations Research**

Developed a discrete-event simulation of a 52-SKU apparel manufacturing system to study inventory policies, setup-time effects, service levels, production bottlenecks, and operational trade-offs.

The analysis showed that the original **95% fulfillment target and 1,000-unit average inventory constraint could not be achieved simultaneously under the modeled capacity**, and identified a best tested policy under the inventory constraint.

[View repository](https://github.com/fallenAmber/Burgh-Threads-Manufacturing-Simulation)

### Cross-National Survey Analytics
**Python · R · Multivariate Statistics**

Analyzed **69,534 respondents across 68 countries** using a multi-stage statistical workflow including PCA/EFA, CFA, Gaussian-mixture latent profile analysis, MANOVA, multilevel mixed-effects modeling, bootstrapped mediation, and logistic regression.

The project examined cross-national variation in science-related attitudes and climate-policy support.

### ComorbiNet — Disease Comorbidity Network Analysis
**Python · Network Science · Complex Systems**

Modeled large-scale disease comorbidity patterns using multilayer and complex-network methods, including centrality analysis, structural vulnerability, targeted and random percolation, spectral methods, and community structure.

### Operations Research with Gurobi
**Python · Gurobi · Mathematical Optimization**

Implemented optimization models including assignment and workforce-planning problems using mathematical programming and Gurobi.

### NATCHANGE — Sustainable Trail Redesign for IBM Glen
**ArcGIS Pro · QGIS · LiDAR/DEM · Spatial Analysis**

Conducting GIS- and field-based analysis for a climate-resilient trail redesign using elevation data, slope analysis, LiDAR/DEM resources, topographic information, and restoration constraints.

Supported by a **2026 Graduate Student Research Award** from Binghamton University.

### Apollo9 — AI-Assisted Solar Inspection Platform
**Computer Vision · Explainable AI · Streamlit · Backend Integration**

Mentored a six-member senior capstone team developing an AI-assisted solar-panel inspection platform using RGB and thermal models, explainable AI, Streamlit-based applications, backend integration, validation workflows, and deployment-oriented development.

### GrammarQuick for Android
**Java · SQLite · MVC**

Developed an Android grammar-learning application with interactive quizzes, persistent score tracking, local data storage, and modular MVC architecture.

### ICEFoods Online Ordering System
**PHP · MySQL · JavaScript · Bootstrap**
